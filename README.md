# Physics Reversi：表裏のある石への更新

## 今回の更新手順

1. Playを停止し、PhysicsReversiWalkを開きます。
2. Physics Reversi → Walk → Use Two-Sided Stones を選びます。
3. 再びPlayして、練習用の黄色い枠へ黒い予備石を置いてください。

Sceneの石とStone.prefabを更新します。位置や寸法は維持し、初回だけ既存の所属に合う面を上に向けます。再実行時は手で調整した向きを戻しません。黒面は石のローカル+Y、白面は-Yです。側面も上半分が黒、下半分が白です。両色のMaterialはMesh Rendererで編集できます。

## 現在のルール

- 静止後、上を向いている面が所属です。衝突で偶然裏返った場合も所属が変わります。
- 自分の予備石だけを掴めます。予備の持ち主はReserve Owner Id、盤上での所属はOwner Idで別管理します。
- 持ち運び中は掴んだときの表裏を保ちます。
- 置いた石は静止後に一度だけ挟み込みを判定します。投入者の色ではなく、着地した石の上面の色で判定します。
- 捕獲は対象の石を物理的に180度回す動作です。色の塗り替えや所属の強制変更はしません。
- 反転動作中も石は動的なRigidbodyで、周囲にぶつかります。反転方向へ短時間、移動・回転速度を制御し、その後は通常の物理挙動へ戻します。障害物に妨げられた場合も最終的な上面を採用します。
- 反転後は盤面を認識し直します。演出後の配置から連鎖捕獲しません。
- ほぼ横向きに立っている石は、暫定的に所属0・未認識です。Edge Face Toleranceで境界を調整できます。

## 操作

- WASD：移動
- マウス移動：カメラ回転
- 画面中央で近くの自分の予備石を狙い、左クリック：掴む
- もう一度左クリック：離す
- Esc：カーソル解放。Game画面をクリックして再開

## 調整する場所

Rules and local input → Walk Capture Controller:

- Flip Height：反転時の持ち上げ高さ。初期値1.8m
- Flip Duration：反転動作の時間。初期値1.2秒
- Capture Axis：盤を基準にした回転軸

以前のCapture Lift / Capture Spin / Animate Captureは廃止しました。反転は所属を変えるルール動作のため、見た目だけ無効にする設定はありません。

Rules and local input → Walk Board Recognition:

- マスとの重なり、境界許容値、静止判定、上面の判定閾値
- Play中の黒白認識数

石を選択 → Carry Stone:

- Owner Id：静止後の上面から決まる所属（黒1、白2、判定不能0）
- Reserve Owner Id：予備石の持ち主
- Recognition：認識結果の詳細

保存する変更はPlayを止めてから行ってください。

## 確認してほしいこと

1. 石の上下が白黒に分かれているか。
2. 練習の捕獲で白面から黒面へ反転するか。
3. 衝突で裏返った石の所属も、静止後の上面と一致するか。

コードのコンパイルは警告0・エラー0、ルールテスト36項目が成功しています。Unity内の見た目・反転の手触り・衝突結果は操作確認が必要です。
