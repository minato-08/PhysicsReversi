# Physics Reversi

物理演算で石を扱うリバーシの Unity 試作です。2 人のプレイヤーが 1 台の PC、1 つの画面で同時に歩き回り、石を掴んで運び、盤に置きます。石は表が黒・裏が白の両面で、**いま上を向いている面**がその石の所属になります。

- Unity 6（URP、Input System）
- シーン：`Assets/Scenes/PhysicsReversiWalk.unity`
- 手番はありません。黒と白が同時に動きます。

## 操作

操作は「移動」と「掴む・離す」の 2 つだけです。キャラクターは歩いた方向を向きます。

| | ゲームパッド | キーボード |
|---|---|---|
| 黒 | 1 台目：左スティックか十字キーで移動、下のボタン（A / ×）で掴む・離す | WASD で移動、F で掴む・離す |
| 白 | 2 台目：同じ | IJKL で移動、H で掴む・離す |

- ゲームパッドとキーボードはどちらも常に有効で、切り替えの設定はありません。
- 移動は画面基準です。上を入れると画面の奥へ歩きます。
- 掴む：キャラクターの正面にあり、届く範囲でいちばん近い掴める石を掴みます。
- 離す：持っている石は正面の少し先に浮いていて、離すとそこへ落ちます。
- 歩いて石にぶつかる：石を押す

### 画面の見方

- カメラは 1 つで固定です。盤の横から見下ろし、床全体が映ります。左が黒の予備置き場、右が白の予備置き場です。
- いま掴むボタンを押すと掴める石は、カメラから見えているその石の外形（輪郭）だけが黄色い線で縁取られ、内側は薄く色づきます。線は輪郭の内側に描くので、石の形や大きさは変わって見えません。プレイヤーごとに 1 つずつ出ます。届く範囲に掴める石がなければ出ません。
- 持っている石は、同じ方式で、白く細い線と、ごく薄い色づきで示されます。
- 認識されている石（どちらかの所属として数えられている石）があるマスには、四隅に小さな鉤型の印が出ます。印は盤の面に貼り付いた形で、淡い半透明です。石があるのに印が出ないなら、その石は数えられていません。
- 画面上部中央に、黒白それぞれの認識されている石の数が出ます。

## 現在のルール

### 所属と盤面認識

- 石のローカル +Y 面が黒、-Y 面が白です。側面も上半分が黒、下半分が白です。
- 盤面認識は Play 中ずっと、一定間隔（初期値 0.05 秒）で繰り返します。**静止を待ちません**。盤に接地している石は、動いている最中でもその時点の上面で所属が決まります。衝突で偶然裏返った石も所属が変わります。
- 石を盤へ投影した形とマスの重なりで、どのマスの石かを決めます。次の石は認識されません。
  - 予備石、持ち運び中の石
  - ほぼ横向きに立っている石（所属 0）
  - 盤に接地していない石（空中、他の石の上、盤外）
  - マスの境界上にあり、どのマスとも言えない石
  - 同じマスを別の石と取り合って負けた石
- 所属は 2 種類を別々に管理します。`Owner Id` は上面から決まる盤上の所属、`Reserve Owner Id` は予備石の持ち主です。

### 捕獲

- 捕獲は「石を置いたとき」ではなく、**挟む並びが新しくできた瞬間**に起きます。石を置く、歩いて押す、持った石で押す、のどれで並びを作っても同じです。
- 黒白どちらの並びも、同じ盤面から同時に判定します。
- **プレイヤーが起こした動きだけ**が捕獲を起こせます。プレイヤー起因になるのは次の動きと、その石にぶつかられて動いた石です。
  - 離した石
  - 歩いて押した石
  - 持ち主が歩いている最中の持ち石がぶつかった石
- 捕獲は対象の石を物理的に 180 度回す動作です。色の塗り替えや所属の強制変更はしません。
- 反転中も石は動的な Rigidbody で、周囲にぶつかります。障害物に妨げられた場合も、最終的に上を向いた面を採用します。
- 反転で動いた石は新しい捕獲を起こしません（連鎖しません）。捕獲が起きると、その原因になったプレイヤーの動きは使い切られます。
- 一度捕獲を起こした並びは、同じ石の組のままでは再発火しません。並びが `Line Break Seconds` 以上崩れてから作り直すと、再び捕獲できます。
- 反転中の石を含む並びは、反転が終わるまで判定しません。

### 確定した石

認識されている石のうち、同じマスに居続けた石を「確定した石」と呼びます。所属・捕獲・石数は認識されている石で決まり、確定かどうかは関係しません。

- **同じマスに** `Confirm Seconds`（初期値 1.5 秒）続けて認識されると、確定します。
- 確定した石は、そのマスから `Loosen Seconds`（初期値 0.5 秒）続けて外れると未確定に戻ります。一瞬外れただけでは戻りません。
- 隣のマスへ押し出された場合も「外れた」と数えます。未確定に戻り、新しいマスで最初から数え直します。
- 捕獲で裏返っている最中は、宙に浮いていても確定のままです。確定は色と無関係で、裏返った後も続きます。
- 離した石は未確定から始まります。予備石と持ち運び中の石は、確定でも未確定でもありません。
- 初期配置の石も特別扱いせず、開始から約 1.5 秒で確定します。

### 掴める石

- 自分の予備石は掴めます。相手の予備石は掴めません。
- 盤上の石は、**未確定の石なら色を問わず掴めます**。**確定した石は掴めません**。体や持ち石をぶつけてマスから外し、未確定に戻してから掴みます。
- 立っている石、重なった石、盤の外の床にある石は認識されないので、未確定のまま掴めます。
- 離した石は、落ちた場所に関係なく「盤上の石」扱いになります。相手が一度掴んで離した予備石は、確定するまでは自分も掴めます。
- 掴めない石には、黄色い輪郭が出ません。

この範囲は Inspector のスイッチで変えられます。現在のシーンは 3 つともオンです。

- `Allow Placed Stone Pickup`：オフにすると盤上の石は掴めず、予備石だけになります。
- `Allow Opponent Stone Pickup`：オフにすると、盤上の石は上面が自分の色のものだけになります。
- `Lock Confirmed Stones`：オフにすると、確定した石も掴めます（確定を導入する前の挙動）。

### 持った石の向き

- 掴んだ石は、**持ち主の色が上を向く**ように水平へ回ります。相手の色を上にしていた未確定の石を掴むと、裏返って自分の色になります。
- 回るのは物理的な動作で、裏返るまでに約 0.5 秒、水平に落ち着くまでに約 0.8 秒かかります。回りきる前に離すと、途中の向きのまま落ちます。
- `Turn Held Stone To Holder Color` をオフにすると、掴んだときの向きを保ちます（以前の挙動）。

### 床から落ちた石

- 床の外へ落ち、盤より `Fall Depth` 以上低くなった石は、持ち主（`Reserve Owner Id`）の予備置き場へ戻り、予備石に戻ります。
- 戻る場所は、その石の元の置き場所、埋まっていれば同じ持ち主の空いている置き場所です。すべて埋まっていれば置き場の上から落とします。
- 持ち運び中の石は対象外で、離した後に判定します。
- ステージ構造が未確定のため、この扱いは暫定です。

## 調整する場所

`Rules and local input` → **Carry Authority**

- Reach：掴める距離（プレイヤーから石の中心まで）
- Fall Depth：盤よりこれだけ低くなった石を予備へ戻す（初期値 10 m）
- Slot Clearance：予備の置き場所が埋まっているとみなす距離
- Allow Placed Stone Pickup / Allow Opponent Stone Pickup / Lock Confirmed Stones：掴める石の範囲を変えるスイッチ（「掴める石」を参照）
- Turn Held Stone To Holder Color：掴んだ石を持ち主の色が上になるよう回すかどうか

`Rules and local input` → **Walk Board Recognition**

- Update Interval：認識の間隔
- Minimum Overlap：マスと認めるのに必要な重なりの割合
- Boundary Tolerance：1 位と 2 位のマスの差がこれ未満なら境界上として除外
- Edge Face Tolerance：横向きとみなす範囲
- Confirm Seconds：同じマスに認識され続けて、確定するまでの時間
- Loosen Seconds：確定した石がマスから外れ続けて、未確定に戻るまでの時間
- 認識されたマスの印の色と濃さは、マテリアル `WalkAssets/RecognitionRing.mat` で変えられます。
- Play 中の黒白認識数と、確定した石の数（`Confirmed Stones`）

`Rules and local input` → **Walk Capture Controller**

- Flip Duration：反転動作の時間（コード既定値 1.2 秒、現在のシーンは 0.61 秒）
- Flip Height：反転時の持ち上げ高さ（1.8 m）
- Capture Axis：盤を基準にした回転軸
- Line Break Seconds：並びが崩れたとみなすまでの時間
- Flip Release Grace：反転終了後、判定に戻すまでの猶予

石を選択 → **Carry Stone**

- Owner Id：上面から決まる所属（黒 1、白 2、判定不能 0）
- Reserve Owner Id：予備石の持ち主
- Recognition：認識結果の詳細。確定した石は末尾に `/ confirmed` が付きます。

`Rules and local input` → **Local Walk Input**

- Players：操作するプレイヤー。1 番目が黒（1 台目のゲームパッド、WASD と F）、2 番目が白（2 台目のゲームパッド、IJKL と H）
- View：移動方向の基準になるカメラ
- Grab Focus：キャラクターの正面どれだけ先を基準に、掴む石を選ぶか
- Stick Dead Zone：スティックの遊び

プレイヤー → **Walk Player**

- 移動速度、向きを変える速さ、押す強さ、持ち石の追従速度
- 持った石の位置は、プレイヤーの子 `Carry point - adjust hand position` を動かして変えます。

`Main Camera`

- 位置、向き、Field of View を Inspector で直接変えます。専用のスクリプトはありません。

`Play HUD` → **Aim Hud**

- 掴める石の強調：輪郭線の色（`Grab Edge`）、内側の色づき（`Grab Fill`、アルファが濃さ）、線の太さ（`Grab Width`、720p でのピクセル数）。
- 持っている石の強調：`Held Edge`、`Held Fill`、`Held Width`。
- 石数表示の配置や大きさは、Play を止めて Hierarchy の `Score Panel` で編集できます。

保存する変更は Play を止めてから行ってください。

## シーンの組み立て

シーンは手作業ではなく、メニュー `Physics Reversi → Walk` で組み立てます。Play を止め、`PhysicsReversiWalk` を開いた状態で、上から順に実行します。どれも再実行して重複しません。

1. Place Editable Scene Parts：床、盤、予備石、初期 4 石、黒と白のプレイヤー、固定カメラ
2. Add Recognition Rings：盤面認識と、認識中のマスを示す四隅の印（メニュー名は当初のリング表示に由来。再実行すると印の形と色を既定に戻します）
3. Add Capture Rules：捕獲判定
4. Use Two-Sided Stones：石を表裏のある両面石へ更新
5. Place Capture Practice（任意）：練習用の白 1・黒 1 と、置き場所を示す枠。枠に黒石を置くと白が反転します。
6. Add Play HUD：プレイヤーごとの掴める石の強調と、画面上部の石数。肩越しカメラ時代のシーンに実行すると、照準・マップ・カメラ用スクリプトを取り除き、カメラを全体の見える位置へ移します（この移行は 1 回だけで、以後の再実行では手で調整した値を保ちます）。
7. Add Second Player：白プレイヤーがいない古いシーンに白プレイヤーを足します。黒プレイヤーの調整値（移動速度など）を引き継ぎます。実行後に 6 をもう一度実行してください。
8. Add Score HUD（任意）：画面上部中央の石数表示だけを置く旧メニュー。6 を実行済みなら不要です。
9. Bevel Stone Edges（任意）：石のメッシュ（`TwoSidedStone.asset`）を、縁を丸めた形に作り直します。シーンは変更せず、どのシーンを開いていても実行できます。変わるのは見た目だけで、当たり判定は元の円柱のままです。丸みの大きさは `FaceStoneSetup.cs` の `BevelRadius` で変えます。

現在のシーンには Capture Practice の石 2 個が置かれたままです（枠は削除済み）。

## テスト

メニュー `Physics Reversi → Run Rule Checks` で、ルール部分のテスト 67 項目を実行します。見た目・反転の手触り・衝突結果は Play での確認が必要です。
