# Physics Reversi

物理演算で石を扱うリバーシのUnity試作です。2人のプレイヤーが1台のPC、1つの画面で同時に歩き回り、石を掴んで運び、盤に置きます。石は表が黒、裏が白の両面で、**いま上を向いている面**がその石の所属になります。手番はありません。黒と白は同時に動きます。

Unity 6、URP、Input Systemを使っています。本筋のシーンは`Assets/Scenes/PhysicsReversiWalkFlat.unity`で、盤は平面です（「平面版のシーン」を参照）。マスがお椀型のシーン`Assets/Scenes/PhysicsReversiWalk.unity`も残してあります。ただし、2026-10-06に盤を平面と決めたので、お椀型のシーンは今後使わず、更新もしません。

この文書には、お椀型のシーンの説明がまだ残っています。「盤と石の物理」の節は、お椀型のシーンの作りと、そこで測った値です。平面に決めた理由の記録として残しています。

## 操作

操作は「移動」と「掴む・離す」の2つだけです。キャラクターは歩いた方向を向きます。

| | ゲームパッド | キーボード |
|---|---|---|
| 黒 | 1台目。左スティックか十字キーで移動、下のボタン（A / ×）で掴む・離す | WASDで移動、Fで掴む・離す |
| 白 | 2台目。操作は黒と同じ | IJKLで移動、Hで掴む・離す |

ゲームパッドとキーボードはどちらも常に有効で、切り替えの設定はありません。移動は画面基準で、上を入れると画面の奥へ歩きます。

掴むボタンで掴むのは、キャラクターの正面にあり、届く範囲でいちばん近い掴める石です。持っている石は正面の少し先に浮いていて、離すとそこへ落ちます。平面版のシーンでは、ボタンを押し続けると構え、離すと投げます（「平面版の操作」を参照）。

歩いて石にぶつかったときの動きは、シーンによって違います。お椀型のシーンにも石を押す処理はありますが、石が低すぎるため、ほとんどの場面で押せません。プレイヤーは石に乗り上げ、上を歩いて越えます（「盤と石の物理」を参照）。平面版のシーンでは、固定されていない石を押せます。

### 画面の見方

カメラは1つで、固定です。盤の横から見下ろし、床全体が映ります。左が黒の予備置き場、右が白の予備置き場です。

いま掴むボタンを押すと掴める石は、黄色い線で縁取られ、内側が薄く色づきます。縁取るのは、カメラから見えているその石の輪郭だけです。線は輪郭の内側に描くので、石の形や大きさは変わって見えません。この表示はプレイヤーごとに1つずつ出て、届く範囲に掴める石がなければ出ません。持っている石は、同じ方式で、白く細い線とごく薄い色づきで示されます。

認識されている石があるマスには、四隅に小さな鉤型の印が出ます。認識されている石とは、どちらかの所属として数えられている石のことです。印は盤の面に貼り付いた形で、淡い半透明です。石があるのに印が出ないなら、その石は数えられていません。石が確定すると、印は同じ形のまま、はっきりした色に変わります。印が淡いうちは、石は未確定で掴める状態です。

平面版のシーンでは、合法手のルールを試していて、印が2種類増えます（「合法手のルール」を参照）。

- 盤の上の小さな四角は、合法手のマスです。黒い四角は黒が置くと挟めるマス、白い四角は白が置くと挟めるマスを示します。黒の四角はマスの中心より左寄り、白の四角は右寄りに出るので、どちらも置けるマスには2つ並びます。
- 石の上面の中央にある小さな四角は、その石が確定していることを示します。四角のない石は未確定で、掴めます。

画面上部中央には、黒と白それぞれの石の数が出ます。数えるのは、お椀型のシーンでは認識されている石、平面版のシーンでは確定した石です。

### 石の持ち方

持った石は、プレイヤーの正面に、腕の長さだけ離れて浮きます。腕の長さは`Carry point`までの水平距離で、いまは2.1です。プレイヤーが向きを変えると、石は体の周りを回り込んで正面へ来ます。体を横切ることはありません。

石は手の位置へ遅れなく動き、バネでつながれたような伸び縮みはしません。掴んだ直後だけは、石が手元へ寄ってくる動きになります。寄ってくる速さを決めるのは、Walk Playerの`Carry Follow Speed`と`Max Carry Speed`です。

持っている石が何かに阻まれて付いてこられないときは、プレイヤーの動きも制限されます。プレイヤーは石との距離を、腕の長さから0.4を超えて縮めることも広げることもできません。

以前の持ち方と比べた測定値は、次のとおりです。

| | 以前の持ち方 | いまの持ち方 |
|---|---|---|
| 直進中に、石が手の位置から遅れる量 | 0.82 | 0.22 |
| 逆方向へ切り返してから、石が正面に来るまで | 1.2秒たっても来ない | 0.35秒（向きを変え終わるのが0.33秒） |
| 切り返したときの、石と体の中心の最小距離 | 0.46（石の半径は1.3。体を通り抜ける） | 1.88 |

## 現在のルール

平面版のシーンでは、捕獲と確定を「合法手のルール」に切り替えて試しています。この節の「捕獲」と「確定した石」は、切り替える前のルールの説明です。スイッチを戻すと、この説明どおりに動きます。

### 所属と盤面認識

石のローカル+Y面が黒、-Y面が白です。側面も上半分が黒、下半分が白になっています。

盤面認識は、Play中ずっと一定間隔で繰り返します。間隔の初期値は0.05秒です。認識は**石の静止を待ちません**。盤に接地している石は、動いている最中でも、その時点の上面で所属が決まります。衝突で偶然裏返った石も、所属が変わります。

どのマスの石かを決めるのは、石を盤へ投影した形とマスの重なりです。次の石は認識されません。

- 予備石、持ち運び中の石
- ほぼ横向きに立っている石（所属0）
- 盤に接地していない石（空中、他の石の上、盤外）
- マスの境界上にあり、どのマスの石とも決められない石
- 同じマスに別の石が認識され、そのマスの石に選ばれなかった石

所属は2種類あり、別々に管理します。`Owner Id`は上面から決まる盤上の所属で、`Reserve Owner Id`は予備石の持ち主です。

### 捕獲

捕獲は、**挟む並びが新しくできた時点**で起きます。石を置く、歩いて押す、持った石で押す、のどれで並びを作っても同じです。黒と白のどちらの並びも、同じ盤面から同時に判定します。

捕獲を起こせるのは、**プレイヤーが起こした動きだけ**です。プレイヤー起因になるのは、次の石の動きと、その石にぶつかられて動いた石の動きです。

- 離した石
- 歩いて押した石
- 持ち主が歩いている最中の持ち石がぶつかった石

並びのどの位置の石がプレイヤー起因でも、捕獲は起きます。挟まれる側の石でも同じです。そのため、相手の石2個の間に自分の石を置くと、置いた石が相手の色へ裏返ります。この条件は見直す候補があります（`SPEC.md`の「試遊で出た課題」の1）。合法手のルールでは、この裏返りは起きません。

このうち「歩いて押した石」と「持ち石がぶつかった石」は、コードがそう扱うという意味で挙げています。お椀型のシーンでは、どちらも起こせる場面がごく限られます（「盤と石の物理」を参照）。平面版のシーンでは、どちらも起こせます。

捕獲では、対象の石を物理的に180度回します。色の塗り替えや所属の強制変更はしません。反転中も石は動的なRigidbodyのままで、周囲にぶつかります。障害物に妨げられた場合も、最終的に上を向いた面を採用します。

反転で動いた石は新しい捕獲を起こさないので、捕獲は連鎖しません。また、捕獲の原因になったプレイヤーの動きは、それ以降の捕獲を起こせなくなります。

一度捕獲を起こした並びは、同じ石の組のままでは再び捕獲を起こしません。並びが`Line Break Seconds`以上崩れてから作り直すと、再び捕獲できます。反転中の石を含む並びは、反転が終わるまで判定しません。

捕獲が起きると、その並びの両端の石はその時点で確定します。そのため、捕獲に使った石を、確定する前に持ち直して何度も裏返すことはできません。捕獲に使った石を動かすには、崩して未確定に戻す必要があります。捕獲を起こさなかった石は、これまでどおり、確定するまで置き直せます。

### 確定した石

「確定した石」とは、認識されている石のうち、同じマスに居続けた石のことです。所属、捕獲、石数は認識されている石で決まり、確定しているかどうかは関係しません。

石は、同じマスに`Confirm Seconds`続けて認識されると確定します。初期値は1.5秒です。確定した石は、そのマスから`Loosen Seconds`続けて外れると未確定に戻ります。初期値は0.5秒で、一瞬外れただけでは戻りません。隣のマスへ押し出された場合も「外れた」と数えます。押し出された石は未確定に戻り、新しいマスで最初から数え直します。

捕獲で裏返っている最中の石は、宙に浮いていても確定のままです。確定は色と無関係で、裏返った後も続きます。捕獲を起こした並びの両端の石は、時間を待たずにその時点で確定します（「捕獲」を参照）。

離した石は未確定から始まります。予備石と持ち運び中の石は、確定でも未確定でもありません。初期配置の石も特別扱いせず、開始から約1.5秒で確定します。

### 掴める石

自分の予備石は掴めます。相手の予備石は掴めません。盤上の石は、未確定なら色を問わず掴めます。**確定した石は掴めません**。

仕様では、確定した石は体や持ち石をぶつけてマスから外し、未確定に戻してから掴む想定です。お椀型のシーンではこの手段が成り立たず、お椀に収まって確定した石はだれにも動かせません（「盤と石の物理」を参照）。平面版のシーンでは、構えた持ち石や投げで崩せます（「平面版のシーン」を参照）。

立っている石、重なった石、盤の外の床にある石は認識されないので、未確定のまま掴めます。離した石は、落ちた場所に関係なく「盤上の石」扱いです。そのため、相手が一度掴んで離した予備石は、確定するまでは自分も掴めます。掴めない石には、黄色い輪郭が出ません。

掴める石の範囲は、Inspectorのスイッチで変えられます。どちらのシーンも、3つともオンです。

| スイッチ | オフにしたときの挙動 |
|---|---|
| `Allow Placed Stone Pickup` | 盤上の石は掴めず、掴めるのは予備石だけになる |
| `Allow Opponent Stone Pickup` | 盤上の石のうち、掴めるのは上面が自分の色のものだけになる |
| `Lock Confirmed Stones` | 確定した石も掴める。確定を導入する前の挙動 |

### 持った石の向き

掴んだ石は、**持ち主の色が上を向く**ように水平へ回ります。相手の色を上にしていた未確定の石を掴むと、石は裏返って自分の色になります。

回る動きは物理的な動作です。かかる時間は、自分の色の面が上側へ回るまでが約0.3秒、水平に落ち着くまでが約0.85秒です。回りきる前に離すと、石は途中の向きのまま落ちます。

`Turn Held Stone To Holder Color`をオフにすると、石は掴んだときの向きを保ちます。これは以前の挙動です。

### 床から落ちた石

床の外へ落ち、盤より`Fall Depth`以上低くなった石は、持ち主の予備置き場へ戻り、予備石に戻ります。持ち主は`Reserve Owner Id`で決まります。

戻る場所は、その石の元の置き場所です。元の置き場所が埋まっていれば、同じ持ち主の空いている置き場所へ戻します。すべて埋まっていれば、置き場の上から落とします。

持ち運び中の石は対象外です。離した後に判定します。ステージ構造が未確定のため、この扱いは暫定です。

## 盤と石の物理

この節では、お椀型のシーンと、そのアセットの作りを説明します。盤は平面に決めたので、この節の内容は本筋のシーンには当てはまりません。平面に決めた理由の記録として残しています。本筋のシーンの作りは「平面版のシーン」にあります。

数値は2026-10-06にPlayで測りました。プレイヤーが歩く測定は、ゲーム内の時間を毎秒60フレーム相当に固定して行っています。エディタが背面にあると毎秒約10フレームになり、歩いて押す力の出方が実際と変わるためです。

| 対象 | 作り |
|---|---|
| マス | お椀型で、深さ0.45。底の平らな部分は中心から0.7まで。中心から1.9より外は盤の面と同じ高さ（マスの幅は4） |
| 摩擦 | 動0.04、静0.1。低くしてあり、石がお椀の中央へ滑り込む |
| 石 | 半径1.3、厚さ0.36、重さ10。お椀に収まると、上面は盤の面から0.14だけ出る |
| 盤と床 | 盤の面は、周囲の床より0.5高い |
| プレイヤー | カプセル型で、半径0.38、高さ1.8。高さ0.6までの段差を登る（Character Controllerの`Step Offset`）。押す強さは35 |
| 持ち石 | 足元から1.6上、2.1前に浮く |

変える場所は次のとおりです。

| 変える対象 | 場所 |
|---|---|
| 摩擦 | `WalkAssets/Contact.physicMaterial` |
| 石の重さ | `WalkAssets/Stone.prefab`のRigidbody |
| お椀の形 | `WalkAssets/Bowl.asset`（`WalkSceneSetup.cs`の`MakeBowl`が作るメッシュ） |
| 登れる段差 | プレイヤーのCharacter Controllerの`Step Offset` |
| 持ち石の位置 | プレイヤーの子`Carry point - adjust hand position` |

### 盤と石の作りから起きていること

お椀に収まった石は、歩いても押せません。プレイヤーは石に乗り上げ、上を歩いて越えます。平らな床に置いた石でも同じでした。石の高さと登れる段差をPlay中だけ変えて測った結果は、次のとおりです。

| 石の高さ（歩く面から石の上面まで） | 登れる段差 | 結果 |
|---|---|---|
| 0.36（いまの石を平らな床に置いた場合） | 0.6（いまの値） | まったく動かず、乗り越える |
| 0.36 | 0.1 | 動かない（0.01） |
| 0.5 | 0.1 | 押せる（5秒で6.6） |
| 1.08 | 0.1 | 押せる（5秒で15.8） |
| 0.81（マスの境の尾根に乗った石を、隣のお椀の中から押す） | 0.6 | 1.08押せた |

歩いて押すには、石の上面が、登れる段差と、プレイヤーの丸い底（半径0.38）の両方より高い位置にある必要があるようです。いまの石は厚さ0.36でどちらよりも低く、お椀に収まると盤の面から0.14しか出ません。

押せる石は、いまの摩擦だと遠くまで滑ります。上の表のとおり、押せる高さの石は5秒で6.6〜15.8進みました。

持ち石は、置かれた石に当たりません。持ち石は、置かれた石の上面より0.86以上高いところを通ります。

石は、お椀の中央まで滑り落ちるとは限りません。マスの境から0.4内側に落とした石は、尾根の上に水平のまま止まりました。この石は、そのマスの石として認識され、確定もします。

尾根に乗った石は、隣の石の反転で跳ね飛ばされます。尾根の石は隣のマスへはみ出し、隣の石の縁に乗り上げた状態です。捕獲の反転は速度を直接指定して石を動かすので、下の石が反転すると上の石を跳ね上げます。2回測ったところ、上の石は横へ1.05と2.34動きました。そのうち1回では、石が立つ手前まで傾き、どのマスにも認識されない位置で止まっています。乗り上げていない石を反転させたときの横ずれは、0.44以下でした。

以上の結果、**お椀に収まって確定した石を動かす手段が、いまはありません**。この石は掴めず、押せず、持ち石も当たりません。変えられるのは、挟んで裏返す色だけです。`Lock Confirmed Stones`をオフにすると、確定した石も掴めるようになります。

この結果を受けて、盤は平面に決めました。確定した石の動かし方の残りは、`SPEC.md`で検討中です。

## 平面版のシーン

本筋のシーンです。盤を平面にした場合を試すために作り、2026-10-06に、盤は平面と決めました。お椀型のシーンを複製して作るので、お椀型のシーンは変わりません。「盤と石の物理」の節と食い違う点は、この節が正です。

シーンは`Assets/Scenes/PhysicsReversiWalkFlat.unity`です。メニュー`Physics Reversi → Walk → Create Flat Trial Scene`で作ります。このメニューは、お椀型のシーンを複製し、下の表の違いを加えて保存します。すでにシーンがあるときは、手で調整した値を守るために何もしません。作り直すときは、シーンのファイルを消してから実行してください。

| | お椀型（`PhysicsReversiWalk`） | 平面版（`PhysicsReversiWalkFlat`） |
|---|---|---|
| 盤 | お椀型のマス。床より0.5高い | 平面。床と同じ高さ |
| 石が乗る面 | マスごとの当たり判定 | 床1枚。継ぎ目も段差もない。床に`Board Surface`を付け、盤の面として扱う |
| 摩擦 | `Contact`（動0.04、静0.1） | `ContactFlat`（動0.2、静0.25） |
| プレイヤーの当たり | 半径0.38、登れる段差0.6 | 半径0.25、登れる段差0.1 |
| 石を持っているときのボタン | 押すと、すぐ置く | 短く押すと置く。押し続けると構えて溜め、離すと投げる |
| 確定した石の重さ | どれも同じ（10） | マスの中心に近いほど重い（最大4倍） |
| 体で押す強さ | 35 | 110 |
| 石が確定する条件 | 同じマスに1.5秒いる | 合法手のマスに着く（試している） |
| 捕獲が起きる条件 | 挟む並びができる | 合法手のマスに石が着く（試している） |
| 石数の表示 | 認識されている石 | 確定した石（試している） |

オブジェクトの名前は複製元のままで、盤は`Board - 8 x 8 recessed cells`です。ほかのセットアップメニューは、シーン名が`PhysicsReversiWalk`であることを確認するので、平面版では実行できません。平面版に手を入れるメニューは、平面版のシーンを対象にして作ります。

### 平面版の操作

ボタンは1つのままです。石を持っていないときは、これまでどおり、押すと掴みます。石を持っているときは、押した長さで動作が変わります。

0.2秒未満の短い押しは、石をその場に置く操作です。これまでと同じで、石は持っている高さから落ちます。

押し続けると、石を正面の、盤すれすれの高さまで下ろして構えます（押してから0.28秒）。構えた石は置かれた石と同じ高さにあるので、構えたまま歩くと、持ち石で石を押せます。

構えた石は、軽いものとして扱い、上限つきの力で引く作りです。そのため、石は普通に持っているときと同じように付いてきます。当たりは柔らかく、押す強さを決めるのは力の上限だけです。構えた石が動かせない石に当たると、石と一緒にプレイヤーも止まります。

ボタンを離すと、構えていた石をキャラクターの正面へ投げます。押している時間が長いほど速くなり、押してから1.4秒で最大です。1.4秒の内訳は、置くだけになる0.2秒と、溜めの1.2秒です。石が下りきる前に離すと、空中から軽く放る形になります。

溜まり具合を示すのは、持ち石の輪郭です。溜まるほど線が太く、黄色くなります。

### 平面版の固定の強さ

確定した石は、マスの中心に近いほど重くなり、動かしにくくなります。未確定の石と予備石は、元の重さのままです。

石が中心から0.1マス（0.4）以内にあれば、固定の強さは最大で、重さは4倍の40になります。中心から0.45マス（1.8）以上離れていると、固定の強さは0で、重さは10のままです。その間では、固定の強さがなだらかに変わります。

石が動いて中心から離れると、その場で固定が弱くなります。そのため、一度で動かしきれなくても、当てるたびに動かしやすくなる仕組みです。

石を選択すると、Carry Stoneの`Recognition`の末尾に、固定の強さが`hold 82%`のように出ます。

### 合法手のルール

2026-10-06の試遊で、盤面が無秩序になりすぎるという課題が出ました。これを受けて、ふつうのリバーシの合法手を取り入れたルールを、平面版のシーンで試しています。採用はまだ決まっていません。スイッチ3つで、切り替える前のルールへ戻せます。

合法手とは、置くと相手の石を1個以上挟めるマスのことです。挟めるかどうかは、確定した石だけを見て決めます。

- 石が確定するのは、合法手のマスに着いたときだけです。着いた時点で確定し、挟んだ石が裏返ります。同じマスに居続けても、時間では確定しません。
- 合法手でないマスに置いた石は、未確定のまま残ります。だれでも掴めて、体で押せます。石数には数えません。
- 未確定の石は、並びに数えません。未確定の石を端にして挟むことはできず、未確定の石が挟まれることもありません。相手の石2個の間に石を置いても、何も起きません。
- 確定した石がマスから外れて未確定に戻ると、時間がたっても確定し直しません。確定させるには、だれかが掴んで、合法手のマスへ置き直します。
- 初期配置の石は、開始時に確定します。
- 判定は、石がマスに着いたときに1回だけです。置いた石も、押されて着いた石も、同じに扱います。同じマスに居続ける石は、あとで盤面が変わっても判定し直しません。
- 捕獲を起こせるのは、プレイヤーが起こした動きだけです。この点は、切り替える前のルールと同じです。
- 反転中の石を含む並びは、反転が終わってから判定します。

スイッチは次の3つです。

| スイッチ | 場所 | 内容 | 平面版のシーン |
|---|---|---|---|
| Confirm By Time | `Rules and local input`のWalk Board Recognition | オンにすると、同じマスに居続けた石が確定する。オフにすると、確定するのは捕獲を起こした石と、初期配置の石だけになる | オフ |
| Capture By Legal Move | `Rules and local input`のWalk Capture Controller | オンにすると、合法手のマスに着いた未確定の石だけが捕獲を起こし、その石が確定する。オフにすると、挟む並びができた時点で捕獲が起きる | オン |
| Count Confirmed Only | `Play HUD`のScore Hud | オンにすると、石数に確定した石だけを数える | オン |

印を描くのは、`Board Marks`のLegal Move MarksとConfirmed Stone Marksです。色と大きさは、それぞれのInspectorで変えられます。四角は、Playを始めたときに作られます。

2026-10-06にPlayで確かめた結果は、次のとおりです。移動と、掴む・離すの処理を直接呼んで確かめました。キーボードやゲームパッドでの実操作は、まだ確かめていません。

| 場面 | 結果 |
|---|---|
| 黒を合法手のマスへ置く | 離してから0.50秒で確定した。石が落ちて盤に着いた時点にあたる。挟まれた白は、離してから1.10秒で黒になった |
| 黒を合法手でないマスへ置く | 3.5秒たっても未確定のまま。白が掴める状態で、石数は変わらなかった |
| 確定した白2個の間に、黒を置く | 黒は裏返らず、未確定のまま。白2個も変わらなかった |
| 確定した黒を、別のマスへ動かす | 0.8秒後には未確定に戻り、3.8秒後も未確定のまま。石数が1減った |
| スイッチを切り替える前のルールへ戻す | 未確定だった石が時間で確定した。白2個の間に置いた黒は、白へ裏返った |

分かっている点は、次の2つです。

- 判定は、石の静止を待ちません。合法手のマスを滑って通り過ぎる石も、通った時点で挟み、確定します。その石は、マスから出て0.5秒たつと未確定に戻ります。
- 合法手で置いた石も、マスの中心に来るとは限りません。中心からのずれで固定の強さが変わる点は、切り替える前と同じです。

### 平面版で測ったこと

2026-10-06にPlayで測りました。プレイヤーが歩く測定は、毎秒60フレーム相当に固定して行っています。キーボードやゲームパッドでの実操作は、まだ確かめていません。

石は、置いた位置にそのまま止まります。マスの中央から1.2ずらして置いた石は、ずれたまま認識され、確定しました。

歩いて石を押せます。プレイヤーは石を乗り越えず、押したあと石の脇へ回り込みます。石の上を歩いて越えることは、平面版ではできません。押す強さ70ではどの石も動かず、110で、固定されていない石が動きました。そのため、平面版では押す強さを110にしてあります。

捕獲の反転では、石が元の位置へ戻ります。挟まれた石は反転したあと、ずれ0.00で同じマスに戻りました。

石は、継ぎ目に引っかからずに滑ります。マス7個ぶんを横切らせても、高さと傾きのぶれは0でした。石は、速さ6で2.8、速さ12で10.0滑って止まります。

滑る石の減速は、計算より大きく出ます。このプロジェクトの重力は14で、減速は「摩擦係数 × 重力」の約2.2倍でした（摩擦0.2で約6）。そのため、力や速さの値は、計算では決めず、Playで測って決めます。

構えた石は、普通に持っているときと同じように付いてきます。直進中の遅れは0.22です。切り返すと0.37秒で正面へ来ます。体の中心との距離は、1.66以上を保ちます。

中心を外して当てても、持ち石は横へはじかれません。標的の中心を0.6外して当てたとき、持ち石が手の位置から横へずれた量は0.10でした。丸い石どうしなので、標的のほうが斜めへ押し出されます。

投げの強さは、溜めで変わります。4.9先にある同じ重さの石に向けて投げた結果は、次のとおりです。

| 投げた速さ | 結果 |
|---|---|
| 6.0（溜めほぼなし） | 3.6飛んで止まり、届かない |
| 10.5 | 標的を0.97押す。標的はマスに残る |
| 14.0 | 標的を2.73押してマスから出す。投げた石が、そのマスに止まる |

3つの手段の強さは、決めた順番どおりになっています。次の表は、確定した石に当てて動いた距離です。値はいまの初期値で、体で押す強さ110、構えの力150、投げの最大の速さ20、確定石の重さ最大4倍です。体と持ち石は当ててから4.5秒歩き続け、投げは溜め最大で4.9手前から投げました。

| 手段 | 中央の石（固定1.00、重さ40） | 1.2ずれた石（固定0.39、重さ21.8） | 1.8ずれた石（固定0、重さ10） |
|---|---|---|---|
| 体で押す | 0.00 | 0.00 | マスから押し出す |
| 構えた持ち石で当てる | 0.00（自分も止まる） | マスから押し出す | マスから押し出す |
| 溜めて投げる | 1.17 | 2.80（マスから出る） | 6.66（マスから出る） |

中央にきちんと置かれた確定石は、体でも持ち石でも動かず、溜め最大の投げで1.17動きます。1回ではマスから出ませんが、動いた分だけ固定が弱くなるので、繰り返し当てるとマスから出せます。

確定して重くなった石も、捕獲では正しく反転しました。重さ40の石が反転して、ずれ0.00で戻っています。

### 平面版で分かっている課題

- キーボードとゲームパッドでの実操作は、まだ確かめていません。上の結果は、移動と掴む・構える・離すの処理を直接呼んで測ったものです。
- 構えた石が石の間に挟まって付いてこられなくなると、プレイヤーも腕の長さより離れられません。ボタンを離して石を投げると、抜けられます。
- 予備置き場の石も、プレイヤーが歩くと押してしまいます。
- 盤の端から出た石は床の上を滑り、床の外へ落ちると予備へ戻ります。投げの最大の速さでは、外した石が盤の外まで届きます。

2026-10-06に人に遊んでもらって出た課題は、次の3つです。候補は`SPEC.md`の「試遊で出た課題」にあります。

- マスの中心から大きく外れた石も確定するので、盤面が乱れます。
- どの石が確定しているかが、遠目に分かりません。石そのものの見た目は、確定しても変わりません。
- 盤上の石が増えると、動きにくくなります。プレイヤーは石に登れず、確定した石は体で押しのけられません。

「合法手のルール」は、この3つを軽くするための試みです。軽くなったかどうかは、遊んで確かめます。

## シーンの組み立て

シーンは、手作業で配置せず、メニュー`Physics Reversi → Walk`で組み立てます。Playを止め、`PhysicsReversiWalk`を開いた状態で、上から順に実行してください。どのメニューも、再実行してもオブジェクトを重複して追加しません。

1. Place Editable Scene Partsは、床、盤、予備石、初期4石、黒と白のプレイヤー、固定カメラを置きます。
2. Add Recognition Ringsは、盤面認識と、認識中のマスを示す四隅の印を加えます。メニュー名は当初のリング表示に由来します。再実行すると、印の形と色を初期値に戻します。
3. Add Capture Rulesは、捕獲判定を加えます。
4. Use Two-Sided Stonesは、石を表裏のある両面石へ更新します。
5. Place Capture Practiceは任意です。練習用の白石1個と黒石1個、置き場所を示す枠を置きます。枠に黒石を置くと白が反転します。
6. Add Play HUDは、プレイヤーごとの掴める石の強調と、画面上部の石数を加えます。肩越しカメラ時代のシーンに実行すると、照準・マップ・カメラ用のスクリプトを取り除き、カメラを全体の見える位置へ移します。この移行は1回だけで、以後の再実行では手で調整した値を保ちます。
7. Add Second Playerは、白プレイヤーがいない古いシーンに白プレイヤーを足します。黒プレイヤーの調整値（移動速度など）を引き継ぎます。実行後に6をもう一度実行してください。
8. Add Score HUDは任意です。画面上部中央の石数表示だけを置く旧メニューで、6を実行済みなら不要です。
9. Bevel Stone Edgesは任意です。石のメッシュ（`TwoSidedStone.asset`）を、縁を丸めた形に作り直します。シーンは変更しないので、どのシーンを開いていても実行できます。変わるのは見た目だけで、当たり判定は元の円柱のままです。丸みの大きさは`FaceStoneSetup.cs`の`BevelRadius`で変えます。
10. Create Flat Trial Sceneは、平面版のシーンを、お椀型のシーンの複製から作ります（「平面版のシーン」を参照）。開いているシーンに未保存の変更があるときは、実行しません。
11. Add Legal Move Rulesは、平面版のシーンで合法手のルールを有効にします（「合法手のルール」を参照）。`PhysicsReversiWalkFlat`を開いた状態で実行してください。スイッチ3つを合法手のルールの側へ入れ、`Board Marks`を足します。再実行すると、スイッチを合法手のルールの側へ戻します。手で調整した印の色と大きさは保ちます。

どちらのシーンにも、Capture Practiceの石2個が置かれたままです。枠は削除済みです。

## テスト

メニュー`Physics Reversi → Run Rule Checks`で、ルール部分のテスト94項目を実行できます。見た目、反転の動き、衝突結果は、Playで確認する必要があります。
