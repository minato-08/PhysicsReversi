# Physics Reversi

物理演算で石を扱うリバーシの Unity 試作です。2 人のプレイヤーが 1 台の PC、1 つの画面で同時に歩き回り、石を掴んで運び、盤に置きます。石は表が黒・裏が白の両面で、**いま上を向いている面**がその石の所属になります。

- Unity 6（URP、Input System）
- シーン：`Assets/Scenes/PhysicsReversiWalk.unity`（お椀型のマス）
- 試作シーン：`Assets/Scenes/PhysicsReversiWalkFlat.unity`（平面の盤。「平面版の試作シーン」を参照）
- 手番はありません。黒と白が同時に動きます。

## 操作

操作は「移動」と「掴む・離す」の 2 つだけです。キャラクターは歩いた方向を向きます。

| | ゲームパッド | キーボード |
|---|---|---|
| 黒 | 1 台目：左スティックか十字キーで移動、下のボタン（A / ×）で掴む・離す | WASD で移動、F で掴む・離す |
| 白 | 2 台目：同じ | IJKL で移動、H で掴む・離す |

- ゲームパッドとキーボードはどちらも常に有効で、切り替えの設定はありません。
- 移動は画面基準です。上を入れると画面の奥へ歩きます。
- 掴む：キャラクターの正面にあり、届く範囲でいちばん近い掴める石を掴みます。
- 離す：持っている石は正面の少し先に浮いていて、離すとそこへ落ちます。平面版の試作シーンでは、押し続けると構え、離すと投げます（「平面版の操作」を参照）。
- 歩いて石にぶつかる：お椀型のシーンでは、石を押す処理はありますが、石が低すぎて、ほとんどの場面で押せません。プレイヤーは石に乗り上げて、上を歩いて越えます（「盤と石の物理」を参照）。平面版の試作シーンでは、固定されていない石を押せます。

### 画面の見方

- カメラは 1 つで固定です。盤の横から見下ろし、床全体が映ります。左が黒の予備置き場、右が白の予備置き場です。
- いま掴むボタンを押すと掴める石は、カメラから見えているその石の外形（輪郭）だけが黄色い線で縁取られ、内側は薄く色づきます。線は輪郭の内側に描くので、石の形や大きさは変わって見えません。プレイヤーごとに 1 つずつ出ます。届く範囲に掴める石がなければ出ません。
- 持っている石は、同じ方式で、白く細い線と、ごく薄い色づきで示されます。
- 認識されている石（どちらかの所属として数えられている石）があるマスには、四隅に小さな鉤型の印が出ます。印は盤の面に貼り付いた形で、淡い半透明です。石があるのに印が出ないなら、その石は数えられていません。
- その石が確定すると、印は同じ形のまま、はっきりした色に変わります。印が淡いうちは未確定で、掴めます。
- 画面上部中央に、黒白それぞれの認識されている石の数が出ます。

### 石の持ち方

- 持った石は、プレイヤーから腕の長さ（`Carry point` までの水平距離。いまは 2.1）だけ離れた正面にあります。向きを変えると、石は体の周りを回り込んで正面へ来ます。体を横切りません。
- 石は、手の位置へ遅れなく動きます。バネでつながれたような伸び縮みはしません。
- 掴んだ直後だけは、石が手元へ寄ってくる動きになります（**Walk Player** の `Carry Follow Speed`、`Max Carry Speed`）。
- 持っている石が何かに阻まれて付いてこられないときは、プレイヤーも、腕の長さから 0.4 を超えては近づけず、離れられません。

| | 以前の持ち方 | いまの持ち方 |
|---|---|---|
| 直進中に、石が手の位置から遅れる量 | 0.82 | 0.22 |
| 逆方向へ切り返してから、石が正面に来るまで | 1.2 秒たっても来ない | 0.35 秒（向きを変え終わるのが 0.33 秒） |
| 切り返したときの、石と体の中心の最小距離 | 0.46（石の半径は 1.3。体を通り抜ける） | 1.88 |

## 現在のルール

### 所属と盤面認識

- 石のローカル +Y 面が黒、-Y 面が白です。側面も上半分が黒、下半分が白です。
- 盤面認識は Play 中ずっと、一定間隔（初期値 0.05 秒）で繰り返します。**静止を待ちません**。盤に接地している石は、動いている最中でもその時点の上面で所属が決まります。衝突で偶然裏返った石も所属が変わります。
- 石を盤へ投影した形とマスの重なりで、どのマスの石かを決めます。次の石は認識されません。
  - 予備石、持ち運び中の石
  - ほぼ横向きに立っている石（所属 0）
  - 盤に接地していない石（空中、他の石の上、盤外）
  - マスの境界上にあり、どのマスとも言えない石
  - 同じマスを別の石と取り合って負けた石
- 所属は 2 種類を別々に管理します。`Owner Id` は上面から決まる盤上の所属、`Reserve Owner Id` は予備石の持ち主です。

### 捕獲

- 捕獲は「石を置いたとき」ではなく、**挟む並びが新しくできた瞬間**に起きます。石を置く、歩いて押す、持った石で押す、のどれで並びを作っても同じです。
- 黒白どちらの並びも、同じ盤面から同時に判定します。
- **プレイヤーが起こした動きだけ**が捕獲を起こせます。プレイヤー起因になるのは次の動きと、その石にぶつかられて動いた石です。
  - 離した石
  - 歩いて押した石
  - 持ち主が歩いている最中の持ち石がぶつかった石
- 「歩いて押す」と「持ち石がぶつかる」は、コードがそう扱うという意味です。お椀型のシーンでは、どちらも起こせる場面がごく限られます（「盤と石の物理」を参照）。平面版の試作シーンでは、どちらも起こせます。
- 捕獲は対象の石を物理的に 180 度回す動作です。色の塗り替えや所属の強制変更はしません。
- 反転中も石は動的な Rigidbody で、周囲にぶつかります。障害物に妨げられた場合も、最終的に上を向いた面を採用します。
- 反転で動いた石は新しい捕獲を起こしません（連鎖しません）。捕獲が起きると、その原因になったプレイヤーの動きは使い切られます。
- 一度捕獲を起こした並びは、同じ石の組のままでは再発火しません。並びが `Line Break Seconds` 以上崩れてから作り直すと、再び捕獲できます。
- 反転中の石を含む並びは、反転が終わるまで判定しません。
- **捕獲が起きると、その並びの両端の石は、その瞬間に確定します。** 捕獲に使った石を、確定する前に持ち直して何度も裏返すことはできません。動かすには、崩して未確定に戻す必要があります。捕獲を起こさなかった石は、これまでどおり、確定するまで置き直せます。

### 確定した石

認識されている石のうち、同じマスに居続けた石を「確定した石」と呼びます。所属・捕獲・石数は認識されている石で決まり、確定かどうかは関係しません。

- **同じマスに** `Confirm Seconds`（初期値 1.5 秒）続けて認識されると、確定します。
- 確定した石は、そのマスから `Loosen Seconds`（初期値 0.5 秒）続けて外れると未確定に戻ります。一瞬外れただけでは戻りません。
- 隣のマスへ押し出された場合も「外れた」と数えます。未確定に戻り、新しいマスで最初から数え直します。
- 捕獲で裏返っている最中は、宙に浮いていても確定のままです。確定は色と無関係で、裏返った後も続きます。
- 離した石は未確定から始まります。予備石と持ち運び中の石は、確定でも未確定でもありません。
- 捕獲を起こした並びの両端の石は、時間を待たずに、その瞬間に確定します（「捕獲」を参照）。
- 初期配置の石も特別扱いせず、開始から約 1.5 秒で確定します。

### 掴める石

- 自分の予備石は掴めます。相手の予備石は掴めません。
- 盤上の石は、**未確定の石なら色を問わず掴めます**。**確定した石は掴めません**。
- 仕様では、確定した石は体や持ち石をぶつけてマスから外し、未確定に戻してから掴む想定です。**お椀型のシーンではその手段が成り立たず、お椀に収まって確定した石はだれにも動かせません**（「盤と石の物理」を参照）。平面版の試作シーンでは、構えた持ち石や投げで崩せます（「平面版の試作シーン」を参照）。
- 立っている石、重なった石、盤の外の床にある石は認識されないので、未確定のまま掴めます。
- 離した石は、落ちた場所に関係なく「盤上の石」扱いになります。相手が一度掴んで離した予備石は、確定するまでは自分も掴めます。
- 掴めない石には、黄色い輪郭が出ません。

この範囲は Inspector のスイッチで変えられます。どちらのシーンも、3 つともオンです。

- `Allow Placed Stone Pickup`：オフにすると盤上の石は掴めず、予備石だけになります。
- `Allow Opponent Stone Pickup`：オフにすると、盤上の石は上面が自分の色のものだけになります。
- `Lock Confirmed Stones`：オフにすると、確定した石も掴めます（確定を導入する前の挙動）。

### 持った石の向き

- 掴んだ石は、**持ち主の色が上を向く**ように水平へ回ります。相手の色を上にしていた未確定の石を掴むと、裏返って自分の色になります。
- 回るのは物理的な動作で、自分の色の面が上側へ回るまでに約 0.3 秒、水平に落ち着くまでに約 0.85 秒かかります。回りきる前に離すと、途中の向きのまま落ちます。
- `Turn Held Stone To Holder Color` をオフにすると、掴んだときの向きを保ちます（以前の挙動）。

### 床から落ちた石

- 床の外へ落ち、盤より `Fall Depth` 以上低くなった石は、持ち主（`Reserve Owner Id`）の予備置き場へ戻り、予備石に戻ります。
- 戻る場所は、その石の元の置き場所、埋まっていれば同じ持ち主の空いている置き場所です。すべて埋まっていれば置き場の上から落とします。
- 持ち運び中の石は対象外で、離した後に判定します。
- ステージ構造が未確定のため、この扱いは暫定です。

## 盤と石の物理

ルールではなく、シーンとアセットの作りです。仕様として決めたものではありません。数値は 2026-10-06 に Play で測りました。プレイヤーが歩く測定は、ゲーム内の時間を毎秒 60 フレーム相当に固定して行っています。エディタが背面にあると毎秒約 10 フレームになり、歩いて押す力の出方が実際と変わるためです。

| もの | 作り |
|---|---|
| マス | お椀型で、深さ 0.45。底の平らな部分は中心から 0.7 まで。中心から 1.9 より外は盤の面と同じ高さ（マスの幅は 4） |
| 摩擦 | 動 0.04、静 0.1。低くしてあり、石がお椀の中央へ滑り込む |
| 石 | 半径 1.3、厚さ 0.36、重さ 10。お椀に収まると、上面は盤の面から 0.14 だけ出る |
| 盤と床 | 盤の面は、周囲の床より 0.5 高い |
| プレイヤー | カプセル型で、半径 0.38、高さ 1.8。高さ 0.6 までの段差を登る（Character Controller の `Step Offset`）。押す強さは 35 |
| 持ち石 | 足元から 1.6 上、2.1 前に浮く |

変える場所は次のとおりです。

- 摩擦：`WalkAssets/Contact.physicMaterial`
- 石の重さ：`WalkAssets/Stone.prefab` の Rigidbody
- お椀の形：`WalkAssets/Bowl.asset`（`WalkSceneSetup.cs` の `MakeBowl` が作るメッシュ）
- 登れる段差：プレイヤーの Character Controller の `Step Offset`
- 持ち石の位置：プレイヤーの子 `Carry point - adjust hand position`

### この作りから起きていること

- **お椀に収まった石は、歩いても押せません。** プレイヤーは石に乗り上げて、上を歩いて越えます。平らな床に置いた石でも同じでした。石の高さと登れる段差を Play 中だけ変えて測ると、次のとおりでした。

  | 石の高さ（歩く面から石の上面まで） | 登れる段差 | 結果 |
  |---|---|---|
  | 0.36（いまの石を平らな床に置いた場合） | 0.6（いまの値） | まったく動かず、乗り越える |
  | 0.36 | 0.1 | 動かない（0.01） |
  | 0.5 | 0.1 | 押せる（5 秒で 6.6） |
  | 1.08 | 0.1 | 押せる（5 秒で 15.8） |
  | 0.81（尾根に乗った石を、隣のお椀の中から押す） | 0.6 | 1.08 押せた |

  歩いて押すには、石の上面が、登れる段差と、プレイヤーの丸い底（半径 0.38）の両方より高い位置にある必要があるようです。いまの石は厚さ 0.36 でどちらよりも低く、お椀に収まると盤の面から 0.14 しか出ません。
- **押せる石は、いまの摩擦だと遠くまで滑ります。** 上の表のとおり、押せる高さの石は 5 秒で 6.6〜15.8 進みました。
- **持ち石は、置かれた石に当たりません。** 置かれた石の上面より 0.86 以上高いところを通ります。
- **石は、お椀の中央まで滑り落ちるとは限りません。** マスの境から 0.4 内側に落とした石は、尾根の上に水平のまま止まりました。そのマスの石として認識され、確定もします。
- **尾根に乗った石は、隣の石の反転で跳ね飛ばされます。** 尾根の石は隣のマスへはみ出し、隣の石の縁に乗り上げます。捕獲の反転は速度を直接指定して石を動かすので、下の石が反転すると上の石を力ずくで跳ね上げます。2 回測って、上の石は横へ 1.05 と 2.34 動きました。片方の回では、立つ手前まで傾き、どのマスにも認識されない位置で止まりました。乗り上げていない石を反転させたときの横ずれは 0.44 以下でした。
- 以上の結果、**お椀に収まって確定した石を動かす手段が、いまはありません。** 掴めず、押せず、持ち石も当たりません。変えられるのは、挟んで裏返す色だけです。`Lock Confirmed Stones` をオフにすると、確定した石も掴めるようになります。

盤の形と、確定した石の動かし方は、`SPEC.md` で検討中です。

## 平面版の試作シーン

盤を平面にした場合を試すためのシーンです。お椀型のシーンを複製して作るので、元のシーンは変わりません。この節より上の説明は、断りがなければお椀型のシーンのものです。

- シーン：`Assets/Scenes/PhysicsReversiWalkFlat.unity`
- 作り方：メニュー `Physics Reversi → Walk → Create Flat Trial Scene`。お椀型のシーンを複製し、下の表の違いを加えて保存します。
- すでにシーンがあるときは、何もしません。手で調整した値を守るためです。作り直すときは、シーンのファイルを消してから実行します。

| | お椀型（`PhysicsReversiWalk`） | 平面版（`PhysicsReversiWalkFlat`） |
|---|---|---|
| 盤 | お椀型のマス。床より 0.5 高い | 平面。床と同じ高さ |
| 石が乗る面 | マスごとの当たり判定 | 床 1 枚。継ぎ目も段差もない。床に `Board Surface` を付け、盤の面として扱う |
| 摩擦 | `Contact`（動 0.04、静 0.1） | `ContactFlat`（動 0.2、静 0.25） |
| プレイヤーの当たり | 半径 0.38、登れる段差 0.6 | 半径 0.25、登れる段差 0.1 |
| 石を持っているときのボタン | 押すと、すぐ置く | 短く押すと置く。押し続けると構えて溜め、離すと投げる |
| 確定した石の重さ | どれも同じ（10） | マスの中心に近いほど重い（最大 4 倍） |
| 体で押す強さ | 35 | 110 |

オブジェクトの名前は複製元のままです（盤は `Board - 8 x 8 recessed cells`）。ほかのセットアップメニューはシーン名 `PhysicsReversiWalk` を確認するので、平面版では実行できません。

### 平面版の操作

ボタンは 1 つのままです。石を持っていないときは、これまでどおり、押すと掴みます。持っているときは、押した長さで変わります。

- **短く押す**（0.2 秒未満）：その場に置きます。これまでと同じで、持っている高さから落ちます。
- **押し続ける**：石を正面の、盤すれすれの高さまで下ろして構えます（押してから 0.28 秒）。置かれた石と同じ高さなので、構えたまま歩くと、持ち石で石を押せます。
- 構えた石は、軽いものとして扱われ、上限つきの力で引かれます。普通に持っているときと同じように付いてきて、当たりは柔らかく、押す強さは力の上限だけで決まります。
- 構えた石が動かせない石に当たると、石だけが置いていかれるのではなく、自分も止まります。
- **離す**：構えていた石を、キャラクターの正面へ投げます。押している時間が長いほど速く、押してから 1.4 秒で最大になります（置くだけになる 0.2 秒と、溜めの 1.2 秒）。
- 溜まり具合は、持ち石の輪郭で分かります。溜まるほど線が太く、黄色くなります。
- 石が下りきる前に離すと、空中から軽く放る形になります。

### 平面版の固定の強さ

確定した石は、マスの中心に近いほど重くなり、動かしにくくなります。未確定の石と予備石は、元の重さのままです。

- 中心から 0.1 マス（0.4）以内なら、固定の強さは最大で、重さは 4 倍の 40 になります。
- 中心から 0.45 マス（1.8）以上離れていると、固定の強さは 0 で、重さは 10 のままです。その間は、なだらかに変わります。
- 石が動いて中心から離れると、その場で固定が弱くなります。一度で動かしきれなくても、当てるたびに動かしやすくなります。
- 石を選択すると、**Carry Stone** の `Recognition` の末尾に `hold 82%` のように出ます。

### 平面版で測ったこと

2026-10-06 に Play で測りました。プレイヤーが歩く測定は、毎秒 60 フレーム相当に固定して行っています。キーボードやゲームパッドでの実操作は、まだ確かめていません。

- **石は、置いた位置にそのまま止まります。** マスの中央から 1.2 ずらして置いた石は、ずれたまま認識され、確定しました。
- **歩いて石を押せます。** プレイヤーは石を乗り越えず、押したあと石の脇へ回り込みます。石の上を歩いて越えることは、できなくなります。押す強さ 70 ではどの石も動かず、110 で、固定されていない石が動きました。平面版では 110 にしてあります。
- **捕獲の反転は、元の位置へ戻ります。** 挟まれた石は反転したあと、ずれ 0.00 で同じマスに戻りました。
- **石は、継ぎ目に引っかからずに滑ります。** マス 7 個ぶんを横切らせても、高さと傾きのぶれは 0 でした。速さ 6 で 2.8、速さ 12 で 10.0 滑って止まります。
- **滑る石の減速は、計算より大きく出ます。** このプロジェクトの重力は 14 で、減速は「摩擦係数 × 重力」の約 2.2 倍でした（摩擦 0.2 で約 6）。力や速さの値は、計算ではなく Play で測って決めます。
- **構えた石は、普通に持っているときと同じように付いてきます。** 直進中の遅れは 0.22 で、切り返すと 0.37 秒で正面へ来ます。体の中心との距離は、1.66 以上を保ちます。
- **中心を外して当てても、持ち石は横へ逃げません。** 標的の中心を 0.6 外して当てたとき、持ち石が手の位置から横へずれた量は 0.10 でした。丸い石どうしなので、標的のほうが斜めへ押し出されます。
- **投げは、溜めで強さが変わります。** 4.9 先にある同じ重さの石に向けて投げた結果です。

  | 投げた速さ | 結果 |
  |---|---|
  | 6.0（溜めほぼなし） | 3.6 飛んで止まり、届かない |
  | 10.5 | 標的を 0.97 押す。標的はマスに残る |
  | 14.0 | 標的を 2.73 押してマスから出す。投げた石が、そのマスに止まる |

- **3 つの手段は、決めた順番どおりの強さになっています。** いまの既定値（体で押す強さ 110、構えの力 150、投げの最大の速さ 20、確定石の重さ最大 4 倍）で、確定した石に当てて動いた距離です。体と持ち石は当ててから 4.5 秒歩き続け、投げは溜め最大で 4.9 手前から投げました。

  | 手段 | 中央の石（固定 1.00、重さ 40） | 1.2 ずれた石（固定 0.39、重さ 21.8） | 1.8 ずれた石（固定 0、重さ 10） |
  |---|---|---|---|
  | 体で押す | 0.00 | 0.00 | マスから押し出す |
  | 構えた持ち石で当てる | 0.00（自分も止まる） | マスから押し出す | マスから押し出す |
  | 溜めて投げる | 1.17 | 2.80（マスから出る） | 6.66（マスから出る） |

  中央にきちんと置かれた確定石は、体でも持ち石でも動かず、溜め最大の投げで 1.17 動きます。1 回ではマスから出ませんが、動いた分だけ固定が弱くなるので、繰り返し当てると出せます。
- **確定して重くなった石も、捕獲では正しく反転します。** 重さ 40 の石が反転して、ずれ 0.00 で戻りました。

### 平面版で分かっている粗さ

- キーボードとゲームパッドでの実操作は、まだ確かめていません。上の結果は、移動と掴む・構える・離すの処理を直接呼んで測ったものです。
- 構えた石が石の間に挟まって付いてこられなくなると、プレイヤーも腕の長さより離れられません。離す（投げる）と抜けられます。
- 予備置き場の石も、歩くと押してしまいます。
- 盤の端から出た石は床の上を滑り、床の外へ落ちると予備へ戻ります。投げの最大の速さでは、外した石が盤の外まで届きます。

### 平面版で調整する場所

- 摩擦：`WalkAssets/ContactFlat.physicMaterial`
- 体で押す強さ：プレイヤー → **Walk Player** の `Push Strength`
- 構えと投げ：`Rules and local input` → **Carry Authority** の `Ready and throw`
  - Allow Throw：オフにすると、お椀型のシーンと同じく、押すとすぐ置きます。
  - Tap Seconds：これより短く押すと、置くだけになります。
  - Charge Seconds：溜めが最大になるまでの時間
  - Min / Max Throw Speed：溜めなし、溜め最大のときの投げる速さ
  - Ready Height：構えた石の高さ（持ち主の位置から石の中心まで）
  - Ready Force：構えた石を引く力の上限。持ち石で押す強さになります。
  - Ready Weight：構えた石を、元の重さの何倍のものとして扱うか（既定 0.025）。小さいほど動き出しが速く、当たりが柔らかくなります。押す強さは変わりません。
- 溜めの表示：`Play HUD` → **Aim Hud** の `Charged Edge`、`Charged Width`
- 固定の強さ：`Rules and local input` → **Walk Board Recognition** の `Confirmed stones`
  - Hold Multiplier：中央に置かれた確定石の重さの倍率。1 で、固定の強さを切ります。
  - Full Hold Distance：マスの中心からこの距離（マス単位）までは、固定が最大
  - Zero Hold Distance：この距離（マス単位）で、固定が 0。辺の中点が 0.5
- プレイヤーの当たりと登れる段差：プレイヤー → **Character Controller** の `Radius`、`Step Offset`

## 調整する場所

`Rules and local input` → **Carry Authority**

- Reach：掴める距離（プレイヤーから石の中心まで）
- Fall Depth：盤よりこれだけ低くなった石を予備へ戻す（初期値 10 m）
- Slot Clearance：予備の置き場所が埋まっているとみなす距離
- Allow Placed Stone Pickup / Allow Opponent Stone Pickup / Lock Confirmed Stones：掴める石の範囲を変えるスイッチ（「掴める石」を参照）
- Turn Held Stone To Holder Color：掴んだ石を持ち主の色が上になるよう回すかどうか

`Rules and local input` → **Walk Board Recognition**

- Update Interval：認識の間隔
- Minimum Overlap：マスと認めるのに必要な重なりの割合
- Boundary Tolerance：1 位と 2 位のマスの差がこれ未満なら境界上として除外
- Edge Face Tolerance：横向きとみなす範囲
- Confirm Seconds：同じマスに認識され続けて、確定するまでの時間
- Loosen Seconds：確定した石がマスから外れ続けて、未確定に戻るまでの時間
- 認識されたマスの印の色と濃さは、マテリアル `WalkAssets/RecognitionRing.mat` で変えられます。
- Confirmed Mark：確定した石のマスの印の色（アルファが濃さ）
- Play 中の黒白認識数と、確定した石の数（`Confirmed Stones`）

`Rules and local input` → **Walk Capture Controller**

- Flip Duration：反転動作の時間（コード既定値 1.2 秒、現在のシーンは 0.61 秒）
- Flip Height：反転時の持ち上げ高さ（1.8 m）
- Capture Axis：盤を基準にした回転軸
- Line Break Seconds：並びが崩れたとみなすまでの時間
- Flip Release Grace：反転終了後、判定に戻すまでの猶予
- Confirm Capturing Stones：捕獲を起こした並びの両端の石を、その瞬間に確定させるかどうか。オフにすると、置いた石を確定前に持ち直して、何度でも捕獲に使えます。

石を選択 → **Carry Stone**

- Owner Id：上面から決まる所属（黒 1、白 2、判定不能 0）
- Reserve Owner Id：予備石の持ち主
- Recognition：認識結果の詳細。確定した石は末尾に `/ confirmed` が付きます。平面版では、続けて固定の強さが `hold 82%` のように出ます。

`Rules and local input` → **Local Walk Input**

- Players：操作するプレイヤー。1 番目が黒（1 台目のゲームパッド、WASD と F）、2 番目が白（2 台目のゲームパッド、IJKL と H）
- View：移動方向の基準になるカメラ
- Grab Focus：キャラクターの正面どれだけ先を基準に、掴む石を選ぶか
- Stick Dead Zone：スティックの遊び

プレイヤー → **Walk Player**

- Move Speed：移動速度
- Turn Speed：向きを変える速さ。持った石が体の周りを回り込む速さも、これで決まります（この 2 倍まで）。
- Push Strength：体で石を押す強さ（お椀型は 35、平面版は 110）
- Carry Follow Speed / Max Carry Speed：掴んだ直後に、石が手元へ寄ってくる速さ。手に収まった後の動きには効きません。
- 持った石の位置は、プレイヤーの子 `Carry point - adjust hand position` を動かして変えます。プレイヤーからの水平距離が腕の長さ、高さが持つ高さになります。

プレイヤー → **Character Controller**

- Step Offset：登れる段差の高さ（お椀型は 0.6、平面版は 0.1）。石を歩いて押せるかどうかに関わります（「盤と石の物理」を参照）。お椀型のシーンでは、盤が床より 0.5 高いので、これより小さくすると盤へ上がれなくなります。

摩擦、石の重さ、お椀の形は「盤と石の物理」を参照してください。

`Main Camera`

- 位置、向き、Field of View を Inspector で直接変えます。専用のスクリプトはありません。

`Play HUD` → **Aim Hud**

- 掴める石の強調：輪郭線の色（`Grab Edge`）、内側の色づき（`Grab Fill`、アルファが濃さ）、線の太さ（`Grab Width`、720p でのピクセル数）。
- 持っている石の強調：`Held Edge`、`Held Fill`、`Held Width`。
- 溜めている石の強調：`Charged Edge`、`Charged Width`（平面版。溜まるにつれて、持っている石の線がこの色と太さへ近づきます）。
- 石数表示の配置や大きさは、Play を止めて Hierarchy の `Score Panel` で編集できます。

保存する変更は Play を止めてから行ってください。

## シーンの組み立て

シーンは手作業ではなく、メニュー `Physics Reversi → Walk` で組み立てます。Play を止め、`PhysicsReversiWalk` を開いた状態で、上から順に実行します。どれも再実行して重複しません。

1. Place Editable Scene Parts：床、盤、予備石、初期 4 石、黒と白のプレイヤー、固定カメラ
2. Add Recognition Rings：盤面認識と、認識中のマスを示す四隅の印（メニュー名は当初のリング表示に由来。再実行すると印の形と色を既定に戻します）
3. Add Capture Rules：捕獲判定
4. Use Two-Sided Stones：石を表裏のある両面石へ更新
5. Place Capture Practice（任意）：練習用の白 1・黒 1 と、置き場所を示す枠。枠に黒石を置くと白が反転します。
6. Add Play HUD：プレイヤーごとの掴める石の強調と、画面上部の石数。肩越しカメラ時代のシーンに実行すると、照準・マップ・カメラ用スクリプトを取り除き、カメラを全体の見える位置へ移します（この移行は 1 回だけで、以後の再実行では手で調整した値を保ちます）。
7. Add Second Player：白プレイヤーがいない古いシーンに白プレイヤーを足します。黒プレイヤーの調整値（移動速度など）を引き継ぎます。実行後に 6 をもう一度実行してください。
8. Add Score HUD（任意）：画面上部中央の石数表示だけを置く旧メニュー。6 を実行済みなら不要です。
9. Bevel Stone Edges（任意）：石のメッシュ（`TwoSidedStone.asset`）を、縁を丸めた形に作り直します。シーンは変更せず、どのシーンを開いていても実行できます。変わるのは見た目だけで、当たり判定は元の円柱のままです。丸みの大きさは `FaceStoneSetup.cs` の `BevelRadius` で変えます。

10. Create Flat Trial Scene：平面版の試作シーンを、お椀型のシーンの複製から作ります（「平面版の試作シーン」を参照）。開いているシーンに未保存の変更があるときは、実行しません。

どちらのシーンにも、Capture Practice の石 2 個が置かれたままです（枠は削除済み）。
